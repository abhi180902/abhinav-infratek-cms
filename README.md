# Abhinav Infratek CMS
A full-stack Construction & Architecture website with an admin CMS for managing projects, services, leadership members, client reviews, and enquiries.
## Live Website
https://abhinavinfratek.in
## Tech Stack
- React.js + Vite
- Java + Spring Boot
- PostgreSQL
- Cloudinary
- Vercel
- Render
## Features
- Responsive construction & architecture website
- Project showcase with image galleries
- Services management
- Leadership team management
- Client reviews
- Enquiry management
- Admin dashboard
- Cloudinary image uploads
- RESTful APIs
## Project Structure
backend/     - Spring Boot REST API
frontend/    - React website & admin dashboard
database/    - Database resources
docs/        - Documentation
## Security
Production credentials, environment variables, and database backups are excluded from the repository.
